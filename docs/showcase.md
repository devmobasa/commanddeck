## Change any shortcut

Open **Settings → Shortcuts** to see CommandDeck's own shortcuts and your
Hyprland bindings in one list. Type a key, such as `super+q`, to find what it
does. Click a shortcut and press new keys to record it. If another binding
already uses those keys, choose **Replace** or **Cancel**. A changed row gets a
↺ button that restores it, and the **…** menu can reset all changes. From the
launcher, **Alt+K** changes or adds the shortcut of the selected row. See
[Hyprland keys](launcher-workflows.md#hyprland-keys) for the details.

## Settings, found

Type a setting's name in the launcher, such as `reduce motion`, and **Enter**
opens Settings at that control: the rest of the window dims around it for a
moment. In Settings, the search field at the top of the sidebar opens the page
with the best match and outlines the control. When you stop typing, the control
lights up, and **Enter** moves to it. **Home** and **End** go to the top or
bottom of a page.

## A calmer Settings

Settings groups its pages in the sidebar, each with a coloured icon. Each page
shows grouped rows with compact switches, choices, and segmented controls.
**Customization → Appearance → Interface font** changes the whole interface
between a sans font and your shell font. Paths, commands, and key chords keep
the shell font. The **Diagnostics** page shows the version, process, socket,
and recent search times, and **Copy debug info** copies them for a bug report.
